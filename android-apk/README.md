# RaahDekho - Android APK Build Guide

## Sabse Easy Tarika (APK banane ka):

### Method 1: AppsGeyser se (2 Minute mein APK) ⭐ RECOMMENDED

1. **https://appsgeyser.com** jao
2. "Website App" select karo
3. URL daalo: `https://kumarraj9435.github.io/Blinkit-GRN-Sheet/RaahDekho.html`
4. App name: `RaahDekho`
5. Icon upload karo (koi bhi map icon)
6. "Create" click karo
7. APK download ho jayega!
8. Phone mein install karo - DONE!

---

### Method 2: Android Studio se Build karo

1. Android Studio download karo: https://developer.android.com/studio
2. "Open Project" se is `android-apk` folder ko open karo
3. `app/src/main/res/drawable/` mein apna app icon daalo (ic_launcher.png)
4. Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK file milegi: `app/build/outputs/apk/debug/app-debug.apk`
6. Phone mein transfer karke install karo!

---
